# Security

This repository contains reference data, offline build scripts and a small
PHP library with no runtime dependencies. It makes no network calls unless a
builder is run with an explicit fetch option.

If you find a security problem, for example a way to make the catalogue
loader accept a modified data file, please report it privately through
GitHub's "Report a vulnerability" option on the Security tab of this
repository. Do not open a public issue for it.

Incorrect data is not a security problem. Open a normal issue with a source.
